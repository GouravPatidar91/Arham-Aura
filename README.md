# Arham Aurà (अर्हम AURA) | Luxury Handcrafted Botanical Candles

> **"Sculpted botanical candles, delicate everlasting floral bouquets, and signature artisanal scents hand-poured from 100% pure soy wax."**  
> Founded & Crafted by **Krisha Jain**

---

## ✨ Features & Architecture

- **Interactive Canvas Frame Scrubbing**: Seamless frame sequence animation dynamically responsive to user scroll & scrub events.
- **Infinite 3D Product Carousel**: Looping signature product showcases with interactive 3D perspective tilt cards, smooth inertia navigation, and touch/swipe support.
- **Botanical Fragrance Pyramid**: Studio still-life interactive cards showcasing Top, Heart, and Base olfactory notes (*Honeyed Pears & Blossoms*, *Daisy & Jasmine*, *Vanilla Orchid & Sandalwood*).
- **Atelier Craftsmanship & Founder Story**: Dedicated showcase celebrating artisanal batch production, natural botanicals, and lead-free cotton wicks.
- **Bespoke Direct Ordering**: Streamlined WhatsApp integration for instant bespoke gifting hampers, bridal favors, and custom orders.
- **Full SEO Optimization**:
  - OpenGraph & Twitter Card protocol integration.
  - JSON-LD Rich Snippet Schema (`@type: Store`, `@type: ItemList`).
  - Google compliant `sitemap.xml` with image extensions and `robots.txt`.
  - Brand logo favicon suite across desktop, tablet, and mobile PWA viewports.

---

## 🛠️ Tech Stack

- **Core**: Semantic HTML5, Vanilla Modern JavaScript (ES6+), Vanilla CSS3 (Custom Properties & Responsive Design System).
- **Typography**: Cormorant Garamond, Cinzel, Great Vibes, Jost, Montserrat, Rozha One.
- **Server**: Lightweight Node.js static & media stream server (`server.js`).

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+ recommended)

### Installation & Local Run
```bash
# Clone the repository
git clone https://github.com/GouravPatidar91/Arham-Aura.git

# Navigate into directory
cd Arham-Aura

# Start local server
node server.js
```

Visit `http://localhost:3000` in your browser.
